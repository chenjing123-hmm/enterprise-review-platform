# 03 ICP备案指引

> 版本：v1.0 | 生效日期：2026年6月 | 负责部门：法务合规部

---

## 一、什么是ICP备案

### 1.1 定义

ICP备案（Internet Content Provider备案），全称为"非经营性互联网信息服务备案"，是指在中国境内提供非经营性互联网信息服务的网站，依法向电信管理机构进行备案登记的制度。

简单来说，凡是面向中国大陆境内提供互联网信息服务的网站，无论是否收费，都必须先取得ICP备案号，才能上线运营。

### 1.2 法律依据

| 法律法规 | 关键条款 | 主要内容 |
|---------|---------|---------|
| 《互联网信息服务管理办法》 | 第四条、第八条 | 国家对经营性互联网信息服务实行许可制度；对非经营性互联网信息服务实行备案制度。未取得许可或未履行备案手续的，不得从事互联网信息服务。 |
| 《非经营性互联网信息服务备案管理办法》 | 第三条至第二十四条 | 详细规定了备案的申请条件、办理流程、变更要求、年检制度等。 |
| 《中华人民共和国电信条例》 | 第七条 | 国家对电信业务经营按照电信业务分类，实行许可制度。 |

### 1.3 备案 vs 许可证的区别

| 对比维度 | ICP备案 | ICP许可证（增值电信业务经营许可证） |
|---------|---------|----------------------------------|
| 适用对象 | 所有网站（含非经营性） | 经营性网站（涉及收费） |
| 法律性质 | 备案制（登记） | 许可制（审批） |
| 办理难度 | 较低 | 较高 |
| 办理周期 | 约20个工作日 | 约60-90个工作日 |
| 办理费用 | 免费（接入商可能收服务费） | 免费（但需满足注册资本等条件） |
| 证书形式 | 备案号（如：京ICP备2024XXXXXX号） | 许可证（纸质证书） |
| 有效期 | 长期有效（信息变更需更新） | 5年（到期需续期） |

> **注意**：本平台作为企业评价平台，如需提供付费会员、付费推广、广告等服务，除ICP备案外，还需取得ICP许可证。详见《05_增值电信ICP许可证办理指引》。

## 二、办理条件

### 2.1 主体资格

| 条件 | 要求 | 说明 |
|------|------|------|
| 主体类型 | 在中国境内依法设立的企业法人、事业单位、社会团体等 | 个人也可备案，但经营性网站建议使用企业主体 |
| 营业执照 | 在有效期内，经营范围包含"互联网信息服务"或相关表述 | 如经营范围不符，需先变更经营范围 |
| 法人代表 | 具有完全民事行为能力，无相关违法犯罪记录 | 需提供法人身份证 |
| 网站负责人 | 如非法人本人，需提供授权委托书及负责人身份证 | 网站负责人需为企业在职员工 |

### 2.2 服务器要求

| 条件 | 要求 | 说明 |
|------|------|------|
| 服务器位置 | 必须在中国大陆境内 | 境外服务器无法办理ICP备案 |
| 接入服务商 | 必须通过具有ISP资质的接入服务商提交 | 如阿里云、腾讯云、华为云等 |
| 服务器数量 | 无特殊要求 | 但需与接入服务商确认备案接入 |

### 2.3 域名要求

| 条件 | 要求 | 说明 |
|------|------|------|
| 域名实名认证 | 域名已完成实名认证 | 域名所有者须与备案主体一致 |
| 域名注册商 | 须为工信部批复的域名注册管理机构 | 大多数主流注册商均可 |
| 域名有效期 | 剩余有效期不少于3个月 | 建议备案前确保域名有效期充足 |
| 域名数量 | 一个备案主体可备案多个域名 | 但需逐一备案 |

### 3.2 各环节详细说明

| 环节 | 操作内容 | 预计时间 | 注意事项 |
|------|---------|---------|---------|
| 1. 准备材料 | 整理所有必需材料，确保材料清晰、完整、有效 | 1-3个工作日 | 材料不全会导致反复提交 |
| 2. 选择接入商 | 在阿里云/腾讯云等平台注册账号，购买服务器 | 即时 | 建议选择主流接入商，备案流程更成熟 |
| 3. 接入商提交 | 填写备案信息表，上传证件扫描件，进行人脸核验 | 1个工作日 | 信息必须真实准确，与证件一致 |
| 4. 接入商初审 | 接入商审核材料完整性，可能会电话核实 | 1-3个工作日 | 保持电话畅通，配合核实 |
| 5. 提交管局 | 接入商审核通过后，提交至主体所在地省通信管理局 | 即时 | 此步骤由接入商完成 |
| 6. 管局审核 | 省通信管理局审核备案材料 | 约20个工作日 | 短信核验需在24小时内完成 |
| 7. 获取备案号 | 审核通过后，系统生成备案号 | 即时 | 备案号格式：XICP备XXXXXXXX号 |
| 8. 网站公示 | 在网站底部展示备案号，链接至工信部备案查询系统 | 1个工作日 | 必须公示，否则可能被处罚 |
| 9. 公安网安备案 | 登录全国公安机关互联网站安全服务平台办理 | 上线后30日内 | 未备案可能被关停 |

## 四、所需材料清单

### 4.1 主体资质材料

| 序号 | 材料名称 | 要求 | 格式 |
|------|---------|------|------|
| 1 | 营业执照副本 | 原件彩色扫描件，在有效期内，经营范围包含"互联网信息服务" | JPG/PNG/PDF |
| 2 | 法定代表人身份证 | 正反面彩色扫描件，在有效期内 | JPG/PNG |
| 3 | 网站负责人身份证 | 正反面彩色扫描件，在有效期内（如非法人，需额外提供授权书） | JPG/PNG |
| 4 | 法人授权书（如需要） | 法人签字并加盖公章，授权网站负责人办理备案 | PDF |
| 5 | 域名证书 | 域名注册商出具的域名注册证书，域名所有者须与备案主体一致 | JPG/PNG/PDF |

### 4.2 网站信息材料

| 序号 | 材料名称 | 要求 | 说明 |
|------|---------|------|------|
| 6 | 网站备案信息真实性核验单 | 接入商提供模板，需网站负责人签字并加盖公章 | 一式三份 |
| 7 | 网站负责人现场核验照片 | 接入商指定背景前拍照，或通过人脸识别完成 | 背景需含接入商名称和时间 |
| 8 | 信息安全承诺书 | 承诺遵守互联网信息服务相关法律法规 | 需加盖公章 |
| 9 | 网站建设方案书（如需要） | 部分省份要求提供，说明网站定位、内容、运营模式等 | 需加盖公章 |

### 4.3 特殊情形附加材料

| 情形 | 附加材料 |
|------|---------|
| 网站负责人非单位法人 | 法人签字并加盖公章的授权委托书 |
| 前置审批网站（新闻、出版、教育、医疗等） | 相应主管部门的前置审批文件 |
| 网站名称涉及"中国""中华""国家"等字样 | 相关主管部门的审批文件 |
| 备案主体为分公司 | 总公司营业执照复印件+授权书 |

## 五、办理周期和费用

### 5.1 办理周期

| 阶段 | 预计时间 | 说明 |
|------|---------|------|
| 材料准备 | 1-3个工作日 | 取决于材料齐全程度 |
| 接入商初审 | 1-3个工作日 | 主流接入商通常1个工作日 |
| 管局审核 | 约20个工作日 | 各省管局审核速度有所差异 |
| 总计 | 约25-30个工作日 | 不含材料准备和驳回重提时间 |

### 5.2 费用

| 费用项目 | 金额 | 说明 |
|---------|------|------|
| 备案本身 | 免费 | 工信部不收取任何备案费用 |
| 接入商服务费 | 免费或少量 | 主流接入商（阿里云、腾讯云、华为云等）通常免费提供备案服务 |
| 幕布/拍照费用 | 0-50元 | 如接入商提供免费幕布，则无需费用 |
| 域名注册 | 50-100元/年 | 域名注册费用 |
| 服务器 | 按需 | 云服务器几百元至几千元/年不等 |

> **总计**：ICP备案本身免费，主要成本为域名和服务器费用。

## 六、备案号公示要求

### 6.1 公示规范

| 要求 | 具体说明 |
|------|---------|
| 公示位置 | 网站首页底部（footer区域），所有页面均需展示 |
| 公示内容 | 备案号，格式为"XICP备XXXXXXXX号-X"（X为省份简称） |
| 链接要求 | 备案号必须链接至工信部备案管理系统（https://beian.miit.gov.cn） |
| 字体大小 | 清晰可辨，建议不小于12px |
| 多域名 | 每个域名对应一个备案号，需分别公示 |

### 6.2 公示示例

```
© 2026 企业评价平台 | XICP备2024XXXXXX号-X | 公安网安备案号 XXXXXX号
```

### 6.3 未公示或公示不规范的后果

| 违规情形 | 处罚措施 | 法律依据 |
|---------|---------|---------|
| 未公示备案号 | 责令限期改正，罚款5000-50000元 | 《非经营性互联网信息服务备案管理办法》第二十二条 |
| 备案号链接失效 | 视为未公示，同上处罚 | 同上 |
| 备案信息变更未更新 | 责令限期改正，逾期不改的罚款 | 同上 |

## 七、常见问题

### 7.1 备案期间网站能否上线？

不能。根据《互联网信息服务管理办法》，未完成ICP备案的网站不得上线运营。备案期间，网站域名应处于无法访问状态（关闭网站或显示备案中提示页）。

### 7.2 备案号可以转让吗？

不可以。ICP备案号与备案主体绑定，不可转让。如网站运营主体变更，需先注销原备案，再由新主体重新备案。

### 7.3 备案信息变更怎么办？

备案信息（主体信息、网站名称、域名、服务器IP等）发生变更时，应在变更后30日内通过接入商提交变更申请。未及时变更可能被注销备案号。

### 7.4 一个主体可以备案多个网站吗？

可以。一个主体可以备案多个网站，每个网站对应一个备案号（如XICP备XXXXXXXX号-1、XICP备XXXXXXXX号-2等）。

### 7.5 备案被驳回的常见原因有哪些？

| 驳回原因 | 占比 | 说明 |
|---------|------|------|
| 网站名称不合规 | 约30% | 网站名称不能包含"中国""中华""国家"等字样，不能与备案主体名称无关 |
| 证件照片不清晰 | 约20% | 营业执照、身份证扫描件需清晰可辨 |
| 信息填写不一致 | 约15% | 备案信息与营业执照、域名证书等不一致 |
| 网站负责人核验问题 | 约15% | 人脸识别未通过、照片不符合要求 |
| 经营范围不符 | 约10% | 营业执照经营范围不包含互联网信息服务 |
| 其他 | 约10% | 前置审批、域名实名认证等问题 |

### 7.6 备案后还需要做什么？

1. **公安网安备案**：网站上线后30日内，登录全国公安机关互联网站安全服务平台（www.beian.gov.cn）办理公安网安备案。
2. **跟帖评论备案**：如网站提供评论功能，需按《互联网跟帖评论服务管理规定》向网信办备案。详见《04_跟帖评论备案指引》。
3. **ICP许可证**：如涉及经营性服务（收费会员、广告等），需办理ICP许可证。详见《05_增值电信ICP许可证办理指引》。
4. **等保测评**：根据业务等级，完成网络安全等级保护测评。
