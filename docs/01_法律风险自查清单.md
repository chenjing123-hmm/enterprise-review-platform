# 01 法律风险自查清单

> 版本：v1.0 | 生效日期：2026年6月 | 负责部门：法务合规部
> 本清单适用于企业评价平台（以下简称"本平台"）日常运营中的法律风险识别与管控，所有责任部门应按检查频率定期自查并留痕。

---

## 一、民事侵权风险

### 1.1 名誉权侵权

| 项目 | 内容 |
|------|------|
| **风险描述** | 用户发布对企业的不实负面评价，或在评价中使用侮辱性、贬损性语言，导致被评价企业社会评价降低，本平台可能因未尽合理审查义务而承担连带侵权责任。 |
| **法律依据** | 《中华人民共和国民法典》第一千零二十四条（名誉权保护）、第一千一百九十四条至一千一百九十七条（网络侵权责任）；《最高人民法院关于审理利用信息网络侵害人身权益民事纠纷案件适用法律若干问题的规定》第九条。 |
| **触发条件** | （1）平台收到被侵权主体通知后未及时采取必要措施；（2）平台知道或应当知道侵权内容存在而未处理；（3）平台对用户评价内容进行编辑、推荐、置顶等主动干预行为；（4）评价内容明显失实且平台未尽合理核实义务。 |
| **防范措施** | （1）建立"通知-删除"机制，收到侵权通知后24小时内处理；（2）敏感词库实时拦截侮辱性词汇；（3）评价内容先审后发，人工审核比例不低于20%；（4）建立黑名单机制，对多次发布违规内容的用户限制发言权限；（5）在用户协议中明确知识产权及内容合法性保证条款。 |
| **检查频率** | 每日（投诉处理及时性）、每周（审核质量抽查）、每月（制度执行情况汇总） |
| **责任人** | 法务合规部负责人（第一责任人）、内容审核团队主管（执行责任人） |

### 1.2 商业信誉侵权

| 项目 | 内容 |
|------|------|
| **风险描述** | 用户捏造、散布虚假事实，恶意诋毁企业商业信誉或商品声誉，若平台明知或应知而未采取必要措施，可能承担连带责任，情节严重的还可能涉及刑事责任。 |
| **法律依据** | 《中华人民共和国民法典》第一千零二十四条；《中华人民共和国反不正当竞争法》第十一条（商业诋毁）；《最高人民法院关于审理不正当竞争民事案件应用法律若干问题的解释》第十七条。 |
| **触发条件** | （1）评价内容涉及具体虚假事实陈述（非主观感受）；（2）同一用户或IP短时间内集中发布大量负面评价；（3）被评价企业提供初步证据证明评价内容失实；（4）评价内容明显与公开信息（如工商信息、行政处罚记录）不符。 |
| **防范措施** | （1）建立异常评价行为风控模型（同IP高频发帖、新注册账号大量评价等）；（2）对被投诉评价要求用户提供在职/消费凭证；（3）对涉及具体事实陈述的评价增加事实核查环节；（4）保留评价元数据（IP、设备指纹、时间戳）作为证据链；（5）建立反向通知机制，向被评价企业告知评价发布情况。 |
| **检查频率** | 每日（风控告警处置）、每周（异常行为模式分析）、每季度（风控模型迭代） |
| **责任人** | 法务合规部负责人、风控工程师（技术执行）、内容审核团队主管 |

### 1.3 不正当竞争

| 项目 | 内容 |
|------|------|
| **风险描述** | 平台自身或用户利用平台实施不正当竞争行为，包括但不限于：竞争对手恶意发布差评打压同行、虚构好评提升自身排名、利用平台数据进行不正当商业利用等。 |
| **法律依据** | 《中华人民共和国反不正当竞争法》第二条（一般条款）、第八条（虚假宣传）、第十一条（商业诋毁）、第十二条（互联网不正当竞争）；《中华人民共和国电子商务法》第十七条、第三十九条。 |
| **触发条件** | （1）平台参与或默许刷评、删评、改评行为；（2）平台对特定企业评价进行选择性展示或排序干预；（3）平台利用评价数据为自营或关联企业导流；（4）发现竞争对手有组织地在本平台发布虚假评价。 |
| **防范措施** | （1）严禁平台内部人员干预评价内容及排序，建立操作日志审计机制；（2）评价排序规则公开透明，禁止付费改评/删评；（3）建立竞品关系识别机制，标记关联企业；（4）与第三方反作弊服务商合作，识别刷评行为；（5）员工签署廉洁及利益冲突申报承诺书。 |
| **检查频率** | 每日（操作日志审计）、每周（刷评行为检测）、每月（利益冲突申报核查） |
| **责任人** | 法务合规部负责人、CTO/技术负责人（操作日志审计）、HR负责人（利益冲突管理） |

### 1.4 个人信息侵权

| 项目 | 内容 |
|------|------|
| **风险描述** | 平台在收集、存储、使用、传输用户个人信息（包括评价内容中可能包含的他人个人信息）过程中，未遵循合法、正当、必要原则，侵害用户或第三方个人信息权益。 |
| **法律依据** | 《中华人民共和国个人信息保护法》第六条至第二十七条（个人信息处理规则）；《中华人民共和国民法典》第一千零三十四条至一千零三十九条（隐私权与个人信息保护）；《中华人民共和国数据安全法》第二十一条至第三十条。 |
| **触发条件** | （1）未经同意收集用户个人信息；（2）超出必要范围收集个人信息；（3）未提供个人信息查阅、更正、删除渠道；（4）评价内容中泄露他人姓名、身份证号、联系方式等个人信息；（5）数据跨境传输未经安全评估；（6）发生数据泄露事件未及时报告。 |
| **防范措施** | （1）发布隐私政策并获取用户明示同意；（2）最小化收集原则，敏感个人信息单独同意；（3）评价内容自动脱敏，过滤身份证号、手机号、银行卡号等敏感信息；（4）建立个人信息权利响应机制（查阅、更正、删除、注销），15个工作日内处理；（5）数据加密存储，传输使用HTTPS/TLS；（6）制定数据安全应急预案，发生泄露48小时内报告网信部门。 |
| **检查频率** | 每日（数据脱敏有效性检查）、每周（权限审计）、每月（个人信息处理合规审计）、每季度（数据安全应急演练） |
| **责任人** | 数据保护官（DPO）、法务合规部负责人、信息安全负责人 |

## 二、行政处罚风险

### 2.1 网信办行政处罚

| 项目 | 内容 |
|------|------|
| **风险描述** | 平台违反《网络安全法》《数据安全法》《个人信息保护法》及《网络信息内容生态治理规定》等法律法规，可能面临国家互联网信息办公室（网信办）的行政处罚，包括警告、罚款、暂停相关业务、停业整顿、吊销相关业务许可证或营业执照等。 |
| **法律依据** | 《中华人民共和国网络安全法》第五十九条至第七十五条；《中华人民共和国数据安全法》第四十四条至第五十二条；《中华人民共和国个人信息保护法》第六十六条至第七十一条；《网络信息内容生态治理规定》第三十四条至第四十条。 |
| **触发条件** | （1）未落实用户实名制要求；（2）未建立内容审核机制，平台出现违法信息未及时处置；（3）未建立投诉举报机制或在规定时限内处理；（4）数据安全保护措施不到位导致数据泄露；（5）未配合监管部门监督检查；（6）未按跟帖评论服务管理规定备案。 |
| **防范措施** | （1）严格落实手机号实名认证+身份证实名认证双重认证机制；（2）建立7x24小时内容审核机制，违法信息发现后立即处置；（3）在显著位置设置投诉举报入口，建立48小时内响应机制；（4）定期开展网络安全等级保护测评（等保三级）；（5）建立监管部门对接机制，指定专人负责配合检查；（6）完成跟帖评论服务备案并保持有效。 |
| **检查频率** | 每日（内容审核日志）、每周（投诉处理时效）、每月（合规制度执行报告）、每季度（等保测评自查）、每年（等保测评复测） |
| **责任人** | 法务合规部负责人、CTO（网络安全）、内容安全负责人 |

### 2.2 市场监督管理局行政处罚

| 项目 | 内容 |
|------|------|
| **风险描述** | 平台涉及虚假宣传、不正当竞争、侵害消费者权益等行为，可能面临市场监督管理局的行政处罚，包括责令改正、罚款、吊销营业执照等。 |
| **法律依据** | 《中华人民共和国反不正当竞争法》第十八条至第二十八条；《中华人民共和国广告法》第五十五条至第七十条；《中华人民共和国电子商务法》第七十六条至第八十四条；《中华人民共和国消费者权益保护法》第五十六条。 |
| **触发条件** | （1）平台发布虚假广告或进行虚假宣传；（2）平台参与或纵容刷单炒信行为；（3）平台对评价数据进行虚假标注或篡改；（4）平台未尽到对平台内经营者的审核义务；（5）用户协议或隐私政策存在不公平格式条款。 |
| **防范措施** | （1）所有对外宣传内容需经法务审核；（2）评价数据全链路保留原始记录，不可篡改；（3）用户协议、隐私政策等格式条款定期进行公平性审查；（4）建立广告内容审核机制；（5）平台评价数据标注"用户生成内容"标识，避免被误解为平台官方评价。 |
| **检查频率** | 每周（对外宣传内容审核）、每月（格式条款合规审查）、每季度（广告内容专项检查） |
| **责任人** | 法务合规部负责人、市场部负责人（宣传内容）、产品负责人（格式条款） |

### 2.3 公安网安行政处罚

| 项目 | 内容 |
|------|------|
| **风险描述** | 平台未履行网络安全保护义务，违反网络安全等级保护制度、未落实安全技术措施、未留存网络日志等，可能面临公安机关网络安全保卫部门的行政处罚。 |
| **法律依据** | 《中华人民共和国网络安全法》第二十一条、第二十五条、第五十九条；《计算机信息网络国际联网安全保护管理办法》第十条、第二十条、第二十一条；《互联网安全保护技术措施规定》第十三条。 |
| **触发条件** | （1）未按规定留存网络日志（不少于六个月）；（2）未采取防范计算机病毒和网络攻击的技术措施；（3）未制定网络安全事件应急预案；（4）未落实网络安全等级保护制度；（5）发生网络安全事件未及时向公安机关报告。 |
| **防范措施** | （1）所有服务器、应用系统日志保留不少于六个月；（2）部署WAF、DDoS防护、IDS/IPS等安全设备；（3）制定网络安全事件应急预案并定期演练；（4）完成网络安全等级保护定级备案及测评（等保三级）；（5）建立与公安机关网安部门的联络机制。 |
| **检查频率** | 每日（安全设备运行状态）、每周（日志留存完整性检查）、每月（安全漏洞扫描）、每季度（应急预案演练）、每年（等保复测） |
| **责任人** | CTO/技术负责人、信息安全工程师、法务合规部负责人 |

## 三、刑事犯罪风险

### 3.1 损害商业信誉、商品声誉罪

| 项目 | 内容 |
|------|------|
| **风险描述** | 平台运营者或用户利用平台捏造并散布虚伪事实，损害他人商业信誉、商品声誉，给他人造成重大损失或者有其他严重情节的，可能构成损害商业信誉、商品声誉罪。 |
| **法律依据** | 《中华人民共和国刑法》第二百二十一条（损害商业信誉、商品声誉罪）；《最高人民法院、最高人民检察院关于办理利用信息网络实施诽谤等刑事案件适用法律若干问题的解释》第九条、第十条。 |
| **触发条件** | （1）平台明知评价内容为虚假信息仍予以发布或传播；（2）平台组织或参与捏造虚假评价；（3）平台以删帖、改评为条件向企业索取财物（即"有偿删帖"）；（4）虚假评价造成被评价企业直接经济损失50万元以上或导致企业停产、破产等严重后果。 |
| **防范措施** | （1）建立严格的评价内容审核机制，对涉嫌虚假的评价进行事实核查；（2）严禁任何形式的"有偿删帖"、"有偿改评"行为，违规员工一律开除并追究法律责任；（3）建立评价溯源机制，所有评价可追溯至发布者；（4）对高频发帖、异常评价行为进行实时监控和预警；（5）定期开展员工刑事合规培训，强化法律意识。 |
| **检查频率** | 每日（异常评价行为监控）、每周（员工操作审计）、每月（刑事合规培训）、每季度（第三方审计） |
| **责任人** | 法务合规部负责人（第一责任人）、CEO（最终责任人）、内容安全负责人 |

### 3.2 诽谤罪

| 项目 | 内容 |
|------|------|
| **风险描述** | 用户利用平台捏造事实诽谤他人（包括企业法定代表人、高管等自然人），情节严重的，发布者可能构成诽谤罪。平台若明知而提供帮助，可能构成共同犯罪或帮助信息网络犯罪活动罪。 |
| **法律依据** | 《中华人民共和国刑法》第二百四十六条（诽谤罪）；《最高人民法院、最高人民检察院关于办理利用信息网络实施诽谤等刑事案件适用法律若干问题的解释》第一条至第四条。 |
| **触发条件** | （1）评价内容针对特定自然人（如企业高管）进行诽谤；（2）同一诽谤信息实际被点击、浏览次数达到5000次以上，或被转发次数达到500次以上；（3）造成被害人精神失常、自残、自杀等严重后果；（4）平台收到被侵权人通知后仍不删除相关诽谤信息。 |
| **防范措施** | （1）敏感词库中纳入针对自然人的侮辱诽谤词汇；（2）对评价内容中出现的自然人姓名进行重点审核；（3）建立快速响应机制，收到诽谤投诉后2小时内处置；（4）评价内容中涉及自然人的具体事实陈述，要求用户提供证据；（5）在用户协议中明确禁止诽谤他人，并告知法律后果。 |
| **检查频率** | 每日（诽谤类投诉处理）、每周（涉自然人评价专项审核）、每月（投诉处置时效统计） |
| **责任人** | 法务合规部负责人、内容审核团队主管 |

### 3.3 非法利用信息网络罪

| 项目 | 内容 |
|------|------|
| **风险描述** | 平台被他人利用发布有关违法犯罪信息，或平台自身设立用于实施违法犯罪活动的通讯群组，情节严重的，可能构成非法利用信息网络罪。 |
| **法律依据** | 《中华人民共和国刑法》第二百八十七条之一（非法利用信息网络罪）；《最高人民法院、最高人民检察院关于办理非法利用信息网络、帮助信息网络犯罪活动等刑事案件适用法律若干问题的解释》第七条至第十条。 |
| **触发条件** | （1）平台设立的评价群组、讨论区被用于实施违法犯罪活动；（2）平台发布有关制作或销售违禁物品、管制物品的违法犯罪信息；（3）平台为实施诈骗等违法犯罪活动发布信息；（4）平台注册账号数量达到一定规模且被用于违法犯罪活动；（5）平台经监管部门责令改正而拒不改正。 |
| **防范措施** | （1）对所有用户生成内容进行敏感词过滤和AI内容审核；（2）建立群组/讨论区监控机制，发现违法信息即时处置；（3）用户实名认证后方可发布内容；（4）建立与公安机关的违法犯罪信息通报机制；（5）定期审查平台内容，及时清理违法违规信息。 |
| **检查频率** | 每日（内容审核日志）、每周（群组/讨论区巡检）、每月（违法犯罪信息通报统计） |
| **责任人** | 法务合规部负责人、内容安全负责人、CTO（技术防控） |

### 3.4 侵犯公民个人信息罪

| 项目 | 内容 |
|------|------|
| **风险描述** | 平台违反国家有关规定，向他人出售或提供公民个人信息，或将在提供服务过程中获得的公民个人信息出售或提供给他人，情节严重或特别严重的，可能构成侵犯公民个人信息罪。 |
| **法律依据** | 《中华人民共和国刑法》第二百五十三条之一（侵犯公民个人信息罪）；《最高人民法院、最高人民检察院关于办理侵犯公民个人信息刑事案件适用法律若干问题的解释》第一条至第十二条。 |
| **触发条件** | （1）非法获取、出售或提供行踪轨迹信息、通信内容、征信信息、财产信息50条以上；（2）非法获取、出售或提供住宿信息、通信记录、健康生理信息、交易信息等可能影响人身、财产安全的公民个人信息500条以上；（3）非法获取、出售或提供其他公民个人信息5000条以上；（4）将在履行职责或提供服务过程中获得的公民个人信息出售或提供给他人，数量达到前述标准一半以上；（5）违法所得5000元以上。 |
| **防范措施** | （1）建立数据分类分级制度，公民个人信息列为最高保护级别；（2）数据访问权限最小化原则，所有数据访问操作留痕；（3）数据导出审批制度，批量导出须经法务+技术双重审批；（4）禁止员工私自导出、复制用户数据，违规行为零容忍；（5）与第三方合作涉及数据共享的，必须签署数据处理协议并进行安全评估；（6）定期开展数据安全审计和员工数据合规培训。 |
| **检查频率** | 每日（数据导出日志审计）、每周（权限审计）、每月（数据安全培训）、每季度（第三方数据合规审计） |
| **责任人** | 数据保护官（DPO）、法务合规部负责人、CTO、信息安全负责人 |

## 四、资质合规风险

### 4.1 ICP备案

| 项目 | 内容 |
|------|------|
| **风险描述** | 平台未完成ICP备案或备案信息发生变更未及时更新，导致网站被关停或面临行政处罚。经营性网站还需取得增值电信业务经营许可证（ICP许可证）。 |
| **法律依据** | 《互联网信息服务管理办法》第四条、第八条、第十九条；《非经营性互联网信息服务备案管理办法》第十一条至第二十四条。 |
| **触发条件** | （1）网站上线前未完成ICP备案；（2）备案信息（主体、域名、服务器等）变更后30日内未更新；（3）备案号未在网站首页底部公示；（4）经营性网站（涉及收费服务）未取得ICP许可证。 |
| **防范措施** | （1）网站上线前完成ICP备案并取得备案号；（2）备案号在网站底部显著位置公示，并链接至工信部备案查询系统；（3）建立备案信息变更台账，变更后30日内完成更新；（4）如涉及收费服务，同步办理ICP许可证；（5）指定专人负责备案维护。 |
| **检查频率** | 每月（备案信息有效性检查）、每季度（备案号公示检查）、信息变更（30日内更新） |
| **责任人** | 法务合规部负责人、运维负责人（备案信息维护） |

### 4.2 增值电信业务经营许可证（ICP许可证）

| 项目 | 内容 |
|------|------|
| **风险描述** | 平台涉及经营性互联网信息服务（如付费会员、付费推广、广告收入等），未取得增值电信业务经营许可证（ICP许可证），属于非法经营。 |
| **法律依据** | 《中华人民共和国电信条例》第七条、第九条、第六十九条；《互联网信息服务管理办法》第七条、第十九条；《电信业务经营许可管理办法》第四条、第六条。 |
| **触发条件** | （1）平台提供有偿信息服务（会员费、广告费、推广费等）；（2）未取得ICP许可证即开展经营性业务；（3）许可证有效期届满未续期；（4）许可证载明事项变更未及时办理变更手续。 |
| **防范措施** | （1）确认平台业务模式是否涉及经营性服务，如涉及则必须办理ICP许可证；（2）满足办理条件（注册资本100万以上、3名以上社保人员、固定经营场所）；（3）按省通信管理局要求提交申请材料；（4）许可证有效期5年，到期前90天办理续期；（5）许可证信息变更后30日内办理变更手续。 |
| **检查频率** | 每月（许可证有效性检查）、每季度（业务模式合规审查）、到期前90天（续期提醒） |
| **责任人** | 法务合规部负责人、行政负责人（资质办理）、CEO（业务模式决策） |

### 4.3 跟帖评论服务备案

| 项目 | 内容 |
|------|------|
| **风险描述** | 平台提供跟帖评论服务（即用户可在平台发布文字、图片、音视频等形式的评论），未按《互联网跟帖评论服务管理规定》完成备案，面临责令整改、暂停服务、罚款等处罚。 |
| **法律依据** | 《互联网跟帖评论服务管理规定》第四条、第九条；《网络信息内容生态治理规定》第十一条至第十五条。 |
| **触发条件** | （1）平台提供发帖、评论、回复、弹幕、点赞、转发等互动功能；（2）未向网信办完成跟帖评论服务备案；（3）备案信息变更未及时更新；（4）未落实"先审后发"制度；（5）未对用户进行实名认证。 |
| **防范措施** | （1）上线前向所在地省级网信办完成跟帖评论服务备案；（2）严格落实"先审后发"制度，所有用户评论经审核后发布；（3）用户实名认证（手机号+身份证）后方可发布评论；（4）建立跟帖评论服务管理制度，包括审核标准、审核流程、人员配备等；（5）备案信息变更后及时报告网信办。 |
| **检查频率** | 每日（先审后发制度执行）、每周（审核人员配备检查）、每月（备案信息检查） |
| **责任人** | 法务合规部负责人、内容安全负责人、产品负责人（评论功能） |
