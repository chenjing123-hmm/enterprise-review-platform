# 06 敏感词拦截词库说明

> 版本：v1.0 | 生效日期：2026年6月 | 负责部门：内容安全团队
> 本文档为敏感词拦截词库的技术与运营说明，供内部内容安全管理人员、技术人员及审核团队参考使用。

---

## 一、词库概述

### 1.1 词库定位

本平台敏感词拦截词库是企业评价平台内容安全体系的核心组件，用于对用户发布的评价、评论、回复等所有用户生成内容（UGC）进行实时检测与过滤，防止违法和不良信息在平台传播，确保平台内容合规。

### 1.2 词库设计原则

| 原则 | 说明 |
|------|------|
| 分层分类 | 按性质分类，按危害程度分级，实现精准拦截 |
| 动态更新 | 定期更新+事件驱动更新+用户反馈驱动更新，保持词库时效性 |
| 平衡精准 | 在拦截率和误拦率之间取得平衡，避免过度拦截影响用户体验 |
| 可追溯 | 所有词条变更记录可追溯，做到有据可查 |
| 依法合规 | 词库内容及处置规则符合法律法规要求 |

| 分类编码 | 分类名称 | 说明 | 典型示例 |

## 三、处置等级说明

### 3.1 处置等级定义

| 处置等级 | 代码 | 说明 | 处置方式 | 用户感知 |
|---------|------|------|---------|---------|
| 直接拦截 | BLOCK | 内容命中高危敏感词，直接拒绝发布 | 内容不予发布，前端提示"内容包含违规信息，请修改后重新提交" | 用户看到拒绝提示，内容不可见 |
| 警告提示 | WARN | 内容命中中危敏感词，允许发布但给出警告 | 内容发布前弹出警告提示，用户确认后仍可发布，但内容被标记 | 用户看到警告，可选择继续发布或修改 |
| 人工审核 | REVIEW | 内容命中不确定敏感词，需要人工判断 | 内容进入人工审核队列，审核通过后发布，驳回则告知原因 | 用户看到"内容审核中"提示 |

### 3.2 处置等级与分类的对应关系

| 分类 | BLOCK（直接拦截） | WARN（警告提示） | REVIEW（人工审核） |
|------|-------------------|-----------------|-------------------|
| POLITICAL | 全部子类 | - | - |
| OTHER（赌博/色情/暴力/诈骗/违禁品） | 全部子类 | - | - |
| INSULT | 明确人身攻击、企业贬损 | 模糊侮辱性表述 | 语境依赖强的表述 |
| DEFAMATION | 明确虚假事实指控 | - | 语境依赖强的表述 |
| PRIVACY | 身份证号、银行卡号 | 手机号（部分场景） | 邮箱、模糊地址 |
| OTHER（广告垃圾） | 明确广告引流 | - | 疑似广告 |

## 六、技术实现

### 6.1 核心算法：DFA Trie树

本平台敏感词匹配采用**DFA（Deterministic Finite Automaton）优化的Trie树**算法，具有以下特点：

| 特性 | 说明 |
|------|------|
| 时间复杂度 | O(n)，n为待检测文本长度，与词库大小无关 |
| 空间复杂度 | O(m*k)，m为词条数量，k为平均词长 |
| 匹配速度 | 单次匹配 <1ms（10KB文本） |
| 内存占用 | 约50MB（1万词条） |
| 支持中文 | 完全支持多字节字符 |

### 6.2 算法原理

```
Trie树结构示例（简化）:

      root
     /  |  \
    骗  黑  垃
    /    |    \
   子   心    圾
   /     |      \
  公     企      广
  司     业      告

检测过程：
输入文本: "这是一家骗子公司"
步骤1: 从root开始，匹配"骗" -> 进入"骗"子树
步骤2: 匹配"子" -> 进入"子"子树
步骤3: 匹配"公" -> 进入"公"子树
步骤4: 匹配"司" -> 到达叶子节点，命中"骗子公司"
结果: 命中敏感词"骗子公司"，分类DEFAMATION，等级BLOCK
```

## 七、误拦截处理流程

### 7.1 误拦截定义

| 误拦截类型 | 定义 | 示例 |
|-----------|------|------|
| 正常内容被拦截 | 正常发布的内容被错误判定为违规 | 包含"黑"字的正常表述被判定为侮辱 |
| 低等级被高判 | 应WARN/REVIEW的内容被判定为BLOCK | 模糊表述被直接拦截 |
| 分类错误 | 内容被错误分类 | 正常批评被判定为诽谤 |

### 8.1 敏感词实体定义（TypeScript）

```typescript
// 敏感词词条实体

  id: string;            // 唯一标识
  word: string;          // 敏感词原文
  category: WordCategory; // 分类
  subCategory: string;   // 子分类编码
```
