# 04 跟帖评论备案指引

> 版本：v1.0 | 生效日期：2026年6月 | 负责部门：法务合规部

---

## 一、概述

### 1.1 什么是跟帖评论服务

跟帖评论服务，是指互联网站、应用程序、互动传播平台以及其他具有舆论属性或社会动员能力的网络平台，以发帖、回复、留言、弹幕、点赞、转发等方式，为用户提供发表文字、符号、表情、图片、音视频等信息的服务。

本平台作为企业评价平台，用户可发布评价、评论、回复等互动内容，属于典型的跟帖评论服务提供者，必须依法完成备案。

### 1.2 法律依据

| 法律法规 | 关键条款 | 主要内容 |
|---------|---------|---------|
| 《互联网跟帖评论服务管理规定》 | 第四条 | 提供跟帖评论服务的，应当依法履行备案手续。 |
| 《互联网跟帖评论服务管理规定》 | 第九条 | 跟帖评论服务提供者未履行备案手续的，由网信部门责令限期改正，拒不改正的，责令暂停相关服务，可并处一万元以上五十万元以下罚款。 |
| 《网络信息内容生态治理规定》 | 第十一条至第十五条 | 规定了内容审核、用户管理、投诉举报等义务。 |
| 《中华人民共和国网络安全法》 | 第二十四条 | 网络运营者为用户提供信息发布服务，应当要求用户提供真实身份信息。 |
| 《具有舆论属性或社会动员能力的互联网信息服务安全评估规定》 | 第二条、第三条 | 规定了安全评估的范围和要求。 |

## 二、适用范围

### 2.1 适用主体

以下类型的互联网信息服务提供者，均须办理跟帖评论服务备案：

| 类型 | 具体说明 | 是否适用本平台 |
|------|---------|---------------|
| 提供发帖功能的网站/APP | 用户可发布主题帖 | 是（用户发布评价帖） |
| 提供评论功能的网站/APP | 用户可对其他内容进行评论 | 是（用户对评价进行评论） |
| 提供回复功能的网站/APP | 用户可对评论进行回复（楼中楼） | 是（评价下的回复功能） |
| 提供弹幕功能的网站/APP | 用户在视频/直播中发送弹幕 | 不适用（本平台无弹幕功能） |
| 提供点赞/转发/分享功能的网站/APP | 用户可对内容进行互动 | 是（评价的点赞/分享功能） |

### 2.2 不适用情形

| 情形 | 说明 |
|------|------|
| 纯信息展示网站 | 无用户互动功能，用户无法发布内容 |
| 企业内部系统 | 不面向公众开放的内部管理系统 |
| 仅提供即时通讯功能 | 如微信、QQ等即时通讯工具（另有专门规定） |

### 3.2 各环节详细说明

| 环节 | 操作内容 | 预计时间 | 注意事项 |
|------|---------|---------|---------|
| 1. 准备材料 | 整理所有必需材料，重点准备安全评估报告和管理制度 | 5-10个工作日 | 安全评估报告需客观、详实 |
| 2. 自行评估 | 对平台用户规模、内容类型、传播能力等进行评估 | 1-3个工作日 | 评估结果直接影响后续监管要求 |
| 3. 提交申请 | 向所在地省级网信办提交书面备案申请及全套材料 | 1个工作日 | 建议提前与网信办沟通确认材料要求 |
| 4. 网信办审核 | 网信办审核材料，可能进行现场核查 | 15-30个工作日 | 保持与网信办沟通渠道畅通 |
| 5. 获取备案号 | 审核通过后，获取备案号或备案回执 | 即时 | 妥善保管备案凭证 |
| 6. 落实合规要求 | 按备案后要求落实各项合规措施 | 上线前完成 | 先审后发是核心要求 |
| 7. 公示备案信息 | 在网站/APP显著位置公示备案信息 | 1个工作日 | 建议放在"关于"或"资质"页面 |
| 8. 定期自查报告 | 按网信办要求提交自查报告 | 按需 | 通常为每季度或每半年 |

## 四、所需材料

### 4.1 核心材料清单

| 序号 | 材料名称 | 要求 | 说明 |
|------|---------|------|------|
| 1 | 跟帖评论服务备案申请表 | 按网信办格式填写，包含主体信息、网站信息、服务内容、用户规模等 | 需加盖公章 |
| 2 | 互联网信息服务安全评估报告 | 按《具有舆论属性或社会动员能力的互联网信息服务安全评估规定》要求编制 | 核心材料，详见4.2 |
| 3 | 跟帖评论服务管理制度 | 包含审核标准、审核流程、人员配备、培训机制、应急处置等 | 需加盖公章 |
| 4 | 技术保障方案 | 包含技术架构、安全措施、数据保护、内容审核技术方案等 | 需CTO签字 |
| 5 | 营业执照副本 | 原件彩色扫描件，在有效期内 | 加盖公章 |
| 6 | 法定代表人身份证 | 正反面扫描件 | 加盖公章 |
| 7 | ICP备案证明 | 已完成ICP备案的证明 | 备案号截图 |
| 8 | 用户实名认证方案 | 说明实名认证的技术实现方式和流程 | 技术文档 |

### 4.2 安全评估报告要点

安全评估报告是备案的核心材料，需包含以下内容：

| 评估维度 | 评估内容 | 评估要点 |
|---------|---------|---------|
| 服务形态 | 平台提供的跟帖评论服务类型 | 发帖、评论、回复、点赞、转发、分享等功能范围 |
| 用户规模 | 预期用户数量及增长趋势 | 注册用户数、日活跃用户数、月活跃用户数 |
| 内容类型 | 用户发布的内容类型 | 文字、图片、表情、音视频等 |
| 舆论属性 | 平台是否具有舆论动员能力 | 信息传播速度、用户互动程度、话题聚合能力 |
| 安全风险 | 可能存在的安全风险 | 违规内容传播风险、用户隐私泄露风险、舆论操纵风险 |
| 安全措施 | 已采取或计划采取的安全措施 | 内容审核机制、用户管理机制、应急响应机制 |
| 管理制度 | 已建立的管理制度 | 审核制度、投诉制度、用户管理制度、培训制度 |

### 4.3 管理制度要点

| 制度名称 | 核心内容 | 重点要求 |
|---------|---------|---------|
| 内容审核制度 | 审核标准、审核流程、审核人员管理 | 先审后发、分级审核、审核留痕 |
| 用户管理制度 | 用户注册、实名认证、行为管理、处罚机制 | 实名认证、黑名单、信用积分 |
| 投诉举报制度 | 投诉渠道、受理流程、处置时限、反馈机制 | 显著位置设置入口、规定时限内处理 |
| 人员培训制度 | 培训内容、培训频率、考核机制 | 审核人员必须持证上岗 |
| 应急管理制度 | 应急响应流程、处置措施、报告机制 | 发现违规立即处置、及时报告 |

## 五、备案后合规要求

### 5.1 核心合规要求

| 要求 | 具体内容 | 法律依据 | 落实措施 |
|------|---------|---------|---------|
| 先审后发 | 所有用户发布的评论须经审核后方可公开发布 | 《互联网跟帖评论服务管理规定》第五条 | 机器初审+人工复审，审核通过后方发布 |
| 实名认证 | 用户须通过真实身份信息认证后方可发布评论 | 《网络安全法》第二十四条 | 手机号+身份证双重认证 |
| 内容审核 | 建立内容审核机制，配备与服务规模相适应的审核人员 | 《互联网跟帖评论服务管理规定》第五条 | 配备专职审核团队，审核人员持证上岗 |
| 数据留存 | 留存用户注册信息、评论内容、审核日志不少于6个月 | 《网络安全法》第二十一条 | 每日自动检查数据留存完整性 |
| 投诉处理 | 设置便捷投诉举报入口，及时处理投诉 | 《互联网跟帖评论服务管理规定》第六条 | 显著位置设置投诉入口，24小时内响应 |
| 用户管理 | 建立用户信用管理制度，对违规用户采取限制措施 | 《互联网跟帖评论服务管理规定》第七条 | 黑名单制度、信用积分制度 |
| 技术保障 | 采取技术措施过滤违法和不良信息 | 《互联网跟帖评论服务管理规定》第八条 | 敏感词库、AI内容审核、风控系统 |
| 信息公示 | 公示服务内容、管理规则、投诉方式等 | 《互联网跟帖评论服务管理规定》第六条 | 在"关于"页面公示 |

### 5.2 审核人员配备要求

| 用户规模 | 最低审核人员数量 | 建议排班模式 |
|---------|-----------------|-------------|
| <10万DAU | 5人 | 工作日白班+周末轮值 |
| 10万-100万DAU | 15人 | 7x16小时（含早晚班） |
| 100万-1000万DAU | 50人 | 7x24小时（三班倒） |
| >1000万DAU | 100人以上 | 7x24小时（多班制） |

### 5.3 审核人员资质要求

| 要求 | 说明 |
|------|------|
| 政治素质 | 拥护党的领导，遵守国家法律法规 |
| 无犯罪记录 | 须提供无犯罪记录证明 |
| 培训考核 | 须通过内容审核培训考核，持证上岗 |
| 保密承诺 | 签署保密协议，不得泄露审核内容 |
| 定期培训 | 每月至少参加一次合规培训 |
| 心理关怀 | 定期进行心理评估，提供心理辅导 |

## 六、未备案处罚

### 6.1 处罚标准

| 违规情形 | 处罚措施 | 法律依据 |
|---------|---------|---------|
| 未备案擅自提供跟帖评论服务 | 责令限期改正；拒不改正的，责令暂停相关服务，可并处一万元以上五十万元以下罚款 | 《互联网跟帖评论服务管理规定》第九条 |
| 备案信息变更未及时更新 | 责令限期改正；拒不改正的，同上处罚 | 同上 |
| 未落实先审后发制度 | 责令限期改正；拒不改正的，责令暂停相关服务，可并处一万元以上五十万元以下罚款 | 同上 |
| 未落实实名认证 | 责令限期改正；拒不改正的，可并处罚款；情节严重的，责令停业整顿 | 《网络安全法》第六十一条 |
| 未建立投诉举报机制 | 责令限期改正；拒不改正的，可并处罚款 | 《互联网跟帖评论服务管理规定》第九条 |
| 审核人员配备不足 | 责令限期改正；拒不改正的，可并处罚款 | 同上 |

### 6.2 典型案例警示

| 案例 | 违规情形 | 处罚结果 |
|------|---------|---------|
| 某社交平台 | 未落实先审后发，用户发布违法信息 | 暂停跟帖评论功能15天，罚款50万元 |
| 某资讯平台 | 未完成跟帖评论备案即上线评论功能 | 责令暂停评论功能，限期整改 |
| 某招聘平台 | 审核人员配备严重不足 | 责令限期整改，增加审核人员至达标 |
| 某论坛 | 未落实实名认证，发布大量违规信息 | 关停论坛板块，罚款30万元 |

## 七、常见问题

### 7.1 跟帖评论备案和ICP备案是什么关系？

两者是独立的备案制度，都需要办理。ICP备案是网站上线的前提条件，跟帖评论备案是提供评论功能的前提条件。一般先完成ICP备案，再办理跟帖评论备案。

### 7.2 备案需要多长时间？

从材料准备到获得备案号，通常需要1-2个月。其中材料准备5-10个工作日，网信办审核15-30个工作日。

### 7.3 备案后还需要做什么？

备案后最重要的任务是落实合规要求：
1. 建立并运行先审后发机制
2. 完成用户实名认证
3. 配备足够的审核人员
4. 建立投诉举报机制
5. 定期向网信办提交自查报告

### 7.4 备案信息变更怎么办？

平台名称、域名、服务内容、主要负责人等发生变更时，应及时向原备案机关报告并更新备案信息。

### 7.5 如果平台只有评价功能，没有"跟帖"（即对评价的评论），是否还需要备案？

如果平台仅提供评价发布功能（用户发布评价，但其他用户不能对该评价进行评论回复），从字面上看没有"跟帖"行为。但从监管实践来看，只要提供用户发布内容的互动功能，建议主动与网信办沟通确认，通常会被要求备案。
